# apps/deploy-panel

Локальная deploy-панель на `Next.js`.

## Что уже есть
- локальный dashboard для системного администратора
- чтение `deploy-panel` API из `apps/api`
- список клиентов, readiness и чеклист запуска
- редактирование существующего `deploy_profile`
- проверка клиента перед деплоем через validation block
- подготовка статуса `validated` после успешной проверки
- workflow-кнопки этапов для движения по статусам деплоя
- workflow-кнопки вызывают отдельные backend endpoints, а не общий update route
- есть отдельный `deploy-run`, который пишет шаги в `audit_log` и завершает сценарий деплоя
- есть отдельный `health-check` блок по API, БД, storage и AI
- есть ручной `rerun health-check` и история последних health-проверок
- есть блок живого preview LMS прямо внутри панели
- preview открывает реальные страницы пилотной LMS, а не отдельную заглушку
- в preview есть живые override-параметры по тарифу и отрасли
- preview зависит от живого `apps/lms-web` на `http://127.0.0.1:3100`; launcher передает этот адрес из конфигурации всем локальным сервисам
- есть поля для `Alice tenant` и `Alice preset`
- есть путь к исходнику LMS и путь к собранному deploy bundle
- можно редактировать тариф, бренд и лимиты клиента
- цветовая настройка убрана из deploy-panel и должна выполняться в отдельном preview-редакторе
- для локального запуска проекта теперь есть отдельная desktop-app `apps/control-center`
- часть интерфейса уже переведена на русский и выровнена под рабочий сценарий системного администратора
- в карточке клиента есть быстрые ссылки на LMS preview и host
- в форме профиля есть блок перехода между тарифами с наглядным списком включаемых и отключаемых функций
- локально проверено, что страница больше не дает горизонтальный скролл

## Команды
- `pnpm --dir apps/deploy-panel dev`
- `pnpm --dir apps/deploy-panel build`
- `pnpm --dir apps/deploy-panel check`

## Переменные окружения
- `DEPLOY_PANEL_API_URL`
- `DEPLOY_PANEL_DEV_USER_ID`
- `DEPLOY_PANEL_DEV_CLIENT_ID`
