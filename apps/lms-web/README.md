# apps/lms-web

Живой runtime и preview для клиентской LMS.

## Что уже есть
- пилотный код полностью находится внутри `apps/lms-web`
- стартовые JSON-данные пилота находятся внутри `apps/lms-web/data/seed`
- внешняя папка пилотного проекта больше не нужна для запуска LMS runtime
- добавлен маршрут `http://127.0.0.1:3100/preview?clientId=...`; порт локального редактора берется из конфигурации Control Center, не из пилотного проекта
- preview читает данные клиента напрямую из `apps/api`
- в preview есть локальная color-панель для быстрого подбора брендинга
- проведен аудит переноса: `C:\Users\KROLL\Desktop\LMS Core\docs\pilot-lms-transfer-audit.md`
- production-сборка `apps/lms-web` проходит после исправления `Suspense` для preview-параметров

## Важное ограничение
Пилотный UI и стартовые данные перенесены, но внутренние данные LMS пока в основном работают через старый локальный `/api/storage` и JSON-файлы.
Следующий крупный шаг - перевести пользователей, обучение, тесты, документы и прогресс на backend API ядра.

## Команды
- `pnpm --dir apps/lms-web dev`
- `pnpm --dir apps/lms-web build`
- `pnpm --dir apps/lms-web check`

Будущее клиентское приложение LMS на `Next.js`.
