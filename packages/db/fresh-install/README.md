# Неиспользуемый черновик генерации

Этот первый черновик подхватил устаревшие JS-модули из src/schema и не соответствует актуальной TypeScript-схеме. Он сохранен только как диагностический артефакт. Не применять SQL из этой папки и не включать его в установочный пакет.

Рабочая baseline генерируется из свежей сборки TypeScript в `../install-baseline`. Исторические миграции `../drizzle` при этом не изменяются.
